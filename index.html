新手教学 — 入门规则

棋盘与回合

  • 六角格棋盘，范围 q, r ∈ [-3, 3]（共 37 格）
  • 每个回合分为：提交行动 → 结算（按速度 3→2→1→0 从快到慢）→ 弹体碰撞 → 清理
  • 每回合每个角色必须提交 1 个主行动；部分角色可额外提交 灵巧行动

防御层级

攻击命中后依次穿透：阵法 → 御剑 → 护盾 → 怒气 → 格挡。穿甲弹跳过所有防御层。

速度系统

速度 3 最快，0 最慢。同速按角色 ID 排序。

  • 速 3：集气护盾、盛怒、纳刀、格挡、上子弹、翻滚
  • 速 2：疾波、居合斩、钩锁、无情铁手、大荒星陨、悬剑
  • 速 1：气功波、普通斩、普通攻击、穿甲弹、如来神掌、枪舞

角色一览

  • 吉米（战士）：呼吸法奇偶切换 + 易经洗髓酒五层突破
  • 枪侠（射手）：每两回合一个灵巧行动点（额外 cost-0 行动）
  • 绝地潜兵（射手）：呼叫补给 + 精准轰炸 + 每回合自动+1 弹
  • 燕双鹰（射手）：对手落空自动装填 + 赌枪取消对手攻击
  • 镜 / 观星者 / 门徒（法师）、逐风剑客 / 破阵武者（战士）：开发中

操作提示

  • 点击角色 → 左侧展开详情面板；点击技能 → 棋盘显示可用范围（蓝色高亮）
  • 悬停目标格 → 显示技能生效范围预览（橙色高亮）
  • 提交行动后点击"执行回合"或等待对手提交后自动执行
  • 底部操作邬显示当前行动角色、资源、Buff 和技能按钮
