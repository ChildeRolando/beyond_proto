# 战斗引擎 — 游戏机制与职业技能参考

## 1. 基础规则

### 1.1 棋盘与坐标

- 六角格棋盘，轴向坐标 `{q, r}`，范围 q, r ∈ [-3, 3]
- 距离计算：`hexDistance = (|q1-q2| + |r1-r2| + |(-q1-r1)-(-q2-r2)|) / 2`
- 相邻格：6 个方向 `[[1,0],[1,-1],[0,-1],[-1,0],[-1,1],[0,1]]`

### 1.2 回合流程

每回合四个阶段：

1. **PLAN** — 双方秘密提交行动指令
2. **RESOLVE** — 按速度 3→2→1→0 依次执行指令（3 最快，0 最慢），同速按 actor ID 排序
3. **EFFECTS** — 弹体在速度层级间飞行，每个 keyframe 检查碰撞、身体接触
4. **CLEANUP** — Buff 持续时间递减（-1=永久），回合结束触发

### 1.3 行动点系统

- 每个角色每回合 **1 个主行动**（必须），提交后不可撤销
- 部分角色拥有 **灵巧行动点**（可选），可在主行动之前或之后提交
- 灵巧行动点由特定 buff 或特质授予，对技能有资格限制

### 1.4 速度系统

速度值 3/2/1/0，3 最快。结算顺序：3→2→1→0。

预瞄技能提供"下回合先制+1"（速度值+1，如 1→2）。

### 1.5 防御层级链

攻击命中目标后，从外到内依次穿透：

```
阵法能量 → 御剑能量 → 护盾(主动) → 怒气抵消 → 格挡
```

| 层 | 防御手段 | 公式 | 来源 | 备注 |
|----|---------|------|------|------|
| 1 | 阵法 | 1 能量 = 1 伤害 | 结阵 | 阵眼被击中则全阵破灭 |
| 2 | 御剑 | 剑能量逐点吸收 | 御剑 | 耗尽则剑碎 |
| 3 | 护盾 | 盾值逐点吸收 | 集气护盾/补盾 | 仅法师，需主动开启 |
| 4 | 怒气 | 2 怒 = 100 伤害 | 战士被动 | 自动触发 |
| 5 | 格挡 | 固定 300 吸收 | 射手格挡 | 永久直到被破甲击破 |

穿甲（`ARMOR_PIERCE` 标志）跳过以上全部防御层。破甲（`BREAK_ARMOR` 标志）额外粉碎护盾、格挡并清零怒气。

### 1.6 弹体系统

- 弹体从发射者飞向目标格，每个速度层级推进一个 keyframe
- 飞行中检查：身体接触（命中角色）、弹体碰撞（强弱判定）、纳刀拦截
- 静止弹体（`STATIONARY`）原地不动，等待角色走入触发身体接触
- 大威力弹体贯穿小威力弹体后继续飞行

### 1.7 Buff 与 Hook 系统

- Buff 通过 `BuffManager` 管理，注册 hook 响应游戏事件
- Hook 类型包括：`ON_BEFORE_MOVE`、`ON_DAMAGE_RECEIVED`、`ON_PROJECTILE_ENTER_RANGE`、`ON_RESOURCE_GAIN`、`ON_RANGE_CALCULATE`、`ON_MOVE_RANGE_CALCULATE`、`ON_POWER_CALCULATE`、`ON_ATTACK_MISSED`、`ON_TARGET_ACQUIRE`、`ON_AFTER_ACTION` 等
- 持续时间：正整数=剩余回合数（每回合 CLEANUP 阶段-1），-1=永久

### 1.8 P2P 联机

- WebSocket 信令服务器中转
- 配置同步：`CONFIG_UPDATE`（职业/角色/带入） → `CONFIG_LOCK` → `BATTLE_START`（host 发送 seed + 双方完整配置）
- 回合协议：`TURN_ACTION`（可多次，取决于行动点数） → `TURN_READY`
- 确定性锁步：seed 固定所有随机因素，双方运行相同逻辑

### 1.9 配置系统

- 职业 → 角色 → 8 个职业技能带入 + 2 个角色池技能带入
- 角色池包含：特质技能（被动）+ 角色专属技能（主动）
- 特质技能标记 `isTrait: true`，不可主动提交，仅在带入后自动生效
- 验证规则：拒绝重复、跨职业、未知技能、隐藏技能

## 2. 资源系统

### 2.1 法师

| 资源 | 初始值 | 上限 | 说明 |
|------|--------|------|------|
| 气(qi) | 0 | 无 | 能量货币，蓄气技能产出 |
| 护盾(shield) | 300 | 无 | 需开启后生效；受击消耗盾值吸收伤害；补盾可回复 |

护盾未开启时不生效。开启方式：`集气护盾`。

### 2.2 战士

| 资源 | 初始值 | 上限 | 说明 |
|------|--------|------|------|
| 怒气(rage) | 0 | 无 | 蓄怒技能产出，命中追加；用于技能消耗和自动防御 |

怒气双重用途：消费=进攻，留存=受击时自动吸收（2 怒=100 伤害）。

### 2.3 射手

| 资源 | 初始值 | 上限 | 说明 |
|------|--------|------|------|
| 弹药(ammo) | 0 | 6 | 射击消费；上子弹从背包装填 |
| 背包弹药(backpackAmmo) | 0 | 无 | 弹壳回收/呼叫补给增加；上子弹时转入弹药 |
| 格挡(blockActive) | true | — | 吸收 300 伤害，永久有效，被破甲后永久失效 |

弹壳机制：射击时掉落弹壳在周围格；翻滚捡起周围弹壳；钩锁路径捡起弹壳。

### 4.2 战士角色

#### 吉米 (warrior_jimmy)
- 特质：
  - 呼吸法(`trait_jimmy_breathing`)：奇偶回合切换「吸」「呼」状态
    - 吸（奇数回合）：怒气获得+1，攻击距离-1
    - 呼（偶数回合）：攻击距离+1，怒气获得-1
- 角色技能：
  - 易经洗髓酒(`role_jimmy_marrow_wine`)：主动技能，速 1，cost 0。消耗怒气突破洗髓层数
    - 层 0→1：消耗 3 怒 → 获得 JIMMY_MARROW_QI（每回合开始怒+1）
    - 层 1→2：消耗 4 怒 → 获得 JIMMY_MARROW_RANGE（攻击距离+1）
    - 层 2→3：消耗 4 怒 → 获得 JIMMY_MARROW_MOVE（移动和易经洗髓酒视为灵巧行动）
    - 层 3→4：消耗 5 怒 → 获得 JIMMY_MARROW_QI2（每回合开始怒+1）
    - 层 4→5：消耗 5 怒 → 获得 JIMMY_MARROW_POWER（威力+100）

#### 逐风剑客 (warrior_duelist)
- 特质：预留特质
- 角色技能：逐风步(`role_duelist_windstep`)（占位）

#### 破阵武者 (warrior_vanguard)

- 角色技能：破阵突进(`role_vanguard_breakline`)（占位）

### 4.3 射手角色
